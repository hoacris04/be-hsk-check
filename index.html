📖 Hướng dẫn tích hợp RSS Feed

🎯 Bước 1: Lấy RSS Feed từ rss.app

  1. Truy cập rss.app
  2. Click "Create Feed"
  3. Chọn nguồn "Facebook"
  4. Nhập link Facebook Page (VD: https://www.facebook.com/HSKTestCenter)
  5. Cấu hình:
    • Feed Name: Đặt tên
    • Number of items: 20-50
    • Update frequency: Every hour
  6. Click "Create Feed"
  7. Copy JSON Feed URL: https://rss.app/feeds/v1.1/XXXXX.json

🔧 Bước 2: Thêm Feed vào Web

  1. Click nút "➕ Thêm nguồn" trên web
  2. Nhập mật khẩu: anhtuandepzai
  3. Điền thông tin:
    • Tên nguồn: VD: "ĐH Khoa học Xã hội"
    • RSS Feed URL: Paste URL từ bước 1
    • Màu gradient: Chọn 2 màu (tùy chọn)
  4. Click "Thêm nguồn"
  5. ✅ Done! Feed mới xuất hiện ngay

🎨 Gợi ý màu gradient

Blue → Purple
Pink → Red
Cyan → Blue
Orange → Red
Green → Teal
Purple → Pink

⚠️ Lưu ý

  • ✅ Facebook page phải là Public
  • ✅ Free plan: Update mỗi giờ, 50 items
  • ✅ Test URL trước khi thêm: Mở trong browser xem có JSON không
  • ✅ Mật khẩu thêm nguồn: anhtuandepzai
